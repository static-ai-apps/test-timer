# Test Timer

A big, simple countdown timer for the kitchen. **[Open it](https://static-ai-apps.github.io/test-timer/)**

- Tap a preset (1, 3, 5, 10 min) or nudge the time by ±1 min / ±10 s, then Start.
- Pause, resume or reset; add time while it runs.
- Beeps and vibrates at zero (repeating until you tap Stop). Keeps the screen awake while running.
- Remembers your last duration; works offline.

It doesn't run several timers at once, and the beep won't sound if your iPhone ringer switch is off.
