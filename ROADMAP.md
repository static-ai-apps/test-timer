# Roadmap

This is the template's example, so none of this will be built here. It shows what a roadmap might look like for a real metronome app.

## Next

1. **Subdivisions.** Eighths, triplets and sixteenths, quieter than the main beat. The most requested feature in metronome app reviews.
2. **Tempo presets.** Save a handful of tempos with names, for working through a setlist.

## Later

- **Tempo ramp:** start slow and speed up gradually, for building speed on a hard passage.
- **Visual-only mode** for practicing in quiet places.

## Not planned

- Accounts or sync: everything stays on the device.
- A tuner: a different job, better as its own app.
